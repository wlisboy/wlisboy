## 使用参数

|参数|说明|
|---|---|
| `-i` / `--info` | 输出最新 Version 版本号 | 
|`-l` / `--latest` | 输出 RARLAB 官网中文版下载地址 |
|`-b` / `--best` | 输出商业中文版下载地址 |
|`-v` / `--version` | 指定历史版本（如 7.20），需与 -l 或 -b 搭配使用，>=7.2 |

## 使用示例 
```
winrar.exe -h
```
